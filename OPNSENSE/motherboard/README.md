### Circled area (bottom-left)

Silk labels in the photo:

- **SATA** — SATA data
- **JFP1** — front panel (power / reset / LEDs)
- **JUSB1** — internal USB header
- **CLR_CMOS** — `1-2 NORMAL`, `2-3 CLEAR CMOS`

Use silk print on the PCB over generic pin tables if they differ slightly between OEM clones.
